💎 DIAMOND ADVENTURE

A fast-paced 2D Platformer game – Bow Combat • Evasion • Diamond Collecting

Diamond Adventure là một game Platformer 2D hành động nơi bạn hóa thân thành một Cung Thủ phiêu lưu qua nhiều màn chơi đầy thử thách.
Người chơi phải bắn cung, né đòn, vượt chướng ngại vật, và thu thập Kim cương để hoàn thành màn chơi.

🌟 Tổng Quan Game

Diamond Adventure kết hợp gameplay platformer cổ điển với cơ chế chiến đấu bằng cung tên từ xa.
Trong mỗi màn, bạn phải:

Tiêu diệt quái vật

Tránh bẫy

Leo trèo, nhảy platform

Thu thập kim cương

Sinh tồn đến cuối màn để hoàn thành nhiệm vụ

Game phù hợp với người chơi yêu thích phong cách phiêu lưu + hành động nhịp độ nhanh.

🔑 Các Tính Năng Chính
🏹 1. Cơ Chế Bắn Cung Đa Dụng

Giữ chuột để "kéo cung" tăng lực bắn

Bắn xa – bắn gần – xuyên giáp tùy lực kéo

Có thể vừa chạy vừa bắn

🔄 2. Né Đòn / Lăn Lộn (Roll)

Giúp thoát skill quái

Vượt khe hẹp

Giảm sát thương khi trúng đòn (tùy bạn có làm hay không)

🧗 3. Gameplay Platformer 2D Cổ Điển

Nhảy, leo, vượt chướng ngại vật

Di chuyển linh hoạt

Cạm bẫy: gai nhọn, hố sâu, quái tấn công

💎 4. Thu Thập Kim Cương

Kim cương dùng để mở khóa kỹ năng / nâng cấp

Ẩn trong nhiều vị trí khó tiếp cận

Là mục tiêu chính của game

🎨 5. Màn Chơi Thiết Kế Thủ Công Đẹp Mắt

Nhiều biome (rừng, hang động, đền cổ…)

Kẻ thù đa dạng

Nhạc nền sống động

🎮 Cách Chơi
Thao tác	Phím (Mặc định)	Mô tả
Di chuyển	A / D	Đi sang trái / phải
Nhảy	Space	Nhảy lên
Lăn – Né	Shift hoặc E	Né đòn, lăn nhanh, vượt khe
Giữ kéo cung	Chuột trái (LMB)	Giữ để kéo cung, tăng lực
Bắn cung	Thả LMB	Thả ra để bắn
Nhặt / Tương tác	F	Nhặt kim cương hoặc tương tác với vật thể
🏗️ Công Nghệ Sử Dụng

Engine: Unity (ví dụ: 2022.3 LTS hoặc version bạn đang dùng)

Ngôn ngữ: C#

Version control: Git / GitHub

2D Tools: Unity Tilemap, Animator, Rigidbody2D
